A.  Deskripsi Aplikasi 
Aplikasi Manajemen Stok dan Penjualan Toko Kelontong adalah 
aplikasi ERP yang berjalan di bidang pengelolaan usaha toko kelontong skala 
kecil (UMKM). Aplikasi ini memiliki modul penjualan (Sales Order) dan 
inventori yang terhubung dalam satu basis data. Aplikasi digunakan oleh 
kasir/admin gudang untuk mencatat transaksi dan stok, serta oleh pemilik toko 
untuk mengelola data barang dan melihat laporan, sehingga stok dan penjualan 
tercatat dengan lebih akurat. 

B.  Tujuan Aplikasi 
Tujuan dari aplikasi ini adalah mempermudah kasir/admin toko 
kelontong dalam mencatat transaksi penjualan dan memantau stok barang 
secara otomatis. Bagi pemilik toko, aplikasi ini bertujuan mempermudah 
pengelolaan data barang serta melihat laporan penjualan dan stok dengan cepat, 
sehingga mengurangi kesalahan pencatatan manual.
